If you find a mistake, please report it with the page URL and a short note about what is wrong.

Useful reports include:

- outdated commands or version numbers
- broken links
- code that no longer runs
- unclear explanations
- duplicated sections
- unsafe or misleading advice

Corrections may lead to a page update, a freshness note, a noindex flag, or archival.
